# موتور نقشه اورجینال بازی

نقشه بازی دیگر یک تصویر یا SVG ثابت نیست. فایل `data/world_polygons.json` شامل چندضلعی‌های ساده‌شده ۱۹۵ کشور است و `GeographyManager` و `world_map.gd` آن‌ها را مستقیماً رسم، رنگ‌گذاری و Hit-test می‌کنند.

هندسه پایه از **Natural Earth 1:50m Admin-0 Countries**، داده عمومی (Public Domain)، گرفته شده و با `tools/build_world_map.py` به فرمت اختصاصی بازی تبدیل شده است:

- منبع: https://github.com/nvkelso/natural-earth-vector
- شرایط استفاده: https://www.naturalearthdata.com/about/terms-of-use/
- خروجی اختصاصی: چندضلعی، حفره، ISO3، ساده‌سازی چندمقیاسی و Web Mercator زمان اجرا

سبک بصری، رنگ لایه‌ها، موتور انتخاب کشور، زوم منطقه‌ای، مسیرها، گلوگاه‌ها و رندر کاملاً متعلق به پروژه است. هیچ CDN، Tile Server یا API نقشه در زمان اجرا لازم نیست.

## نقشه ملی همه کشورها

فایل `data/country_maps.json` نمای نزدیک مستقل هر ۱۹۵ کشور را فراهم می‌کند:

- ۴٬۳۸۶ واحد اداری واقعی سطح اول (استان، ایالت، منطقه و مانند آن)
- ۱٬۹۵۱ شهر شاخص با نام فارسی، مختصات، پایتخت و جمعیت جغرافیایی
- مرز واقعی کشور و تقسیمات از **Natural Earth 1:10m Admin-1**
- شهرها از **Natural Earth 1:10m Populated Places**
- ۹ لایه فارسی: اداری، جمعیت، اقتصاد، زیرساخت، رضایت، امنیت، اقلیم، منابع و نظامی
- نمایش شهر، پایتخت، جاده/ریل مدل‌شده، فرودگاه و بندر راهبردی
- محاسبه شاخص هر منطقه از State زنده، بدون افزودن هندسه ثابت به ذخیره یا Snapshot شبکه

مرز و شهر جغرافیایی است؛ مقدار منطقه‌ای جمعیت، GDP، زیرساخت، رضایت، امنیت، منابع و اهمیت نظامی برآورد دترمینستیک مدل بازی است و در رابط کاربری نیز صریحاً با همین عنوان نمایش داده می‌شود. خروجی با `tools/build_country_maps.py` بازتولید و با `tests/validate_country_maps.py` اعتبارسنجی می‌شود.
