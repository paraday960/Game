## ✅ پیاده‌سازی کامل (با فرمول + عمق + رویداد)

### ۳.۹ منابع و انرژی
- انواع: برق، نفت، گاز، آب، غذا، آهن، مس، مواد صنعتی
- فرمول: تولید = ظرفیت × بازده، خالص = تولید - مصرف، موجودی جدید
- بحران انرژی (ضریب ۰.۵)، بحران غذا (<۱ ماه)
- زنجیره تامین چندلایه، لجستیک، کیفیت، قیمت و نوسان، اثرات زیست‌محیطی
- رویداد: کشف منبع، خشکسالی، بحران جهانی انرژی، تحریم

### ۳.۱۰ اقتصاد و بودجه
- GDP = مصرف + سرمایه‌گذاری + مخارج + صادرات-واردات
- رشد = f(زیرساخت، نیروی کار، فناوری، ثبات)
- مالیات تعادلی، کسری/مازاد، بدهی با سود ۳٪، سقف ۲۰۰٪ GDP
- تورم، بیکاری، منحنی فیلیپس، تراز تجاری
- رویداد: رونق/رکود، بحران بدهی، تورم بالا

### ۳.۱۱ جمعیت و دموگرافی
- رشد = تولد - مرگ + مهاجرت
- نیروی کار، نسبت وابستگی، ترکیب سنی
- رضایت = f(رفاه، بیکاری، تورم، امنیت، بهداشت)
- آستانه شورش <۳۰٪
- رویداد: Baby Boom، اپیدمی، موج مهاجرت

### ۳.۱۲ سیاست و ثبات
- ثبات = f(رضایت، فساد، نابرابری، مشروعیت)
- اعتماد، مشروعیت، تنش
- فساد پویا، آستانه شورش تنش >۸۰٪
- رویداد: اعتراض، کودتا، انتخابات (هر ۴ سال)

### ۳.۱۳ ارتش و دفاع
- قدرت = f(نیرو، تجهیزات، آموزش، فناوری، لجستیک، بودجه)
- آمادگی، هزینه نگهداری ۱۵٪، روحیه ۲۰٪
- بازدارندگی، ۴ شاخه: زمینی ۵۰٪، هوایی ۲۵٪، دریایی ۱۵٪، موشکی ۱۰٪
- رویداد: تنش مرزی، کودتا، بحران آمادگی

### ۳.۱۴ دیپلماسی
- روابط ۰-۱۰۰، آستانه خصومت <۲۵، کاهش اعتماد در پیمان‌شکنی -۲۰
- نفوذ = f(اقتصاد، ارتش، فناوری، قدرت نرم)
- اثر تحریم، هزینه جنگ، شانس صلح
- رویداد: اولتیماتوم، پیمان، جنگ/صلح، تحریم

### ۳.۱۵ زیرساخت
- کیفیت، ظرفیت، گلوگاه (تقاضا/ظرفیت >۱)
- فرسودگی ۵٪ سالانه، اثر +۱۰ کیفیت → +۰.۵٪ رشد
- هزینه نگهداری ۲٪
- رویداد: بلای طبیعی، شکست شبکه، پروژه بزرگ

### ۳.۱۶ فناوری
- نرخ تحقیق = f(بودجه R&D، دانشمندان، آموزش، زیرساخت)
- درخت فناوری، پیش‌نیاز، جاسوسی فناوری
- شاخه‌ها: صنعت، انرژی پاک، پزشکی، نظامی، دیجیتال، فضا
- رویداد: پیشرفت، اختراع، سرقت فناوری
