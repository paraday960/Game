## <a id="اصول"></a>۱. اصول نقشه‌محوری

**قبل:** باید می‌رفتی تب اقتصاد برای بودجه، تب نظامی برای دکترین، تب تجارت برای تحریم

**الان:** همه چیز **از روی نقشه** - روی استان/کشور/مسیر کلیک کن و همونجا مدیریت کن

```
نقشه = قلب بازی
هر کلیک = یک فرمان اتمی
هر فرمان = اثر واقعی روی ۶۵ سامانه
همه دترمینستیک و قابل مشاهده زنده
```

**سه اصل:**
- **دیدن:** هر سیستم یک رنگ روی ۱۹۵ کشور (۳۸ لنز)
- **کلیک:** روی هر استان تمام ۳۳ سیستمش رو می‌بینی
- **اجرا:** همونجا دکمه عملیات می‌زنی و روی نقشه نتیجه رو با انیمیشن می‌بینی

## <a id="لنزها"></a>۳. ۳۸ لنز نقشه - هر سیستم یک رنگ

**چیپ‌های لنز بالا - تک‌انتخابی:**

### گروه پایه (۱۰ تا - اصلی):
| لنز | چی نشون میده | رنگ |
|-----|--------------|-----|
| **سیاسی** | بلوک‌بندی (آسیا/اروپا/آفریقا) | رنگ قاره |
| **روابط** | رابطه با شما ۰-۱۰۰ | قرمز→آبی |
| **جمعیت** | جمعیت لگاریتمی | آبی تیره→روشن |
| **اقتصاد** | GDP لگاریتمی | سبز تیره→روشن |
| **زیرساخت** | کیفیت ۰-۱ | قرمز→سبز |
| **رضایت** | شادی مردم | قرمز→سبز |
| **امنیت** | امنیت عمومی | قرمز→آبی |
| **اقلیم** | برف/سیل/گرما | آبی→قرمز |
| **منابع** | وزن راهبردی | تیره→طلایی |
| **نظامی** | قدرت نظامی/۱۰۰ | تیره→قرمز |

### گروه اقتصادی (۸ تا):
| کشاورزی | امنیت غذایی ۰.۸۵ | سبز |
| صنعت | تولید/۱۵۰ | طوسی→نارنجی |
| تجارت | تنوع صادرات | آبی |
| گردشگری | کیفیت خدمات | فیروزه‌ای |
| بانک مرکزی | ۱-تورم/۰.۳۰ | سبز→قرمز |
| بورس | اعتماد سرمایه‌گذار | قرمز→سبز |
| خرده‌فروشی | رقابت | نارنجی |
| سوخت | پوشش جایگاه | زرد |

### گروه اجتماعی (۷ تا):
بهداشت، آموزش، رفاه (۱-فقر×۲)، خانواده، ورزش جوانان، قومیت (۱-تنش)، فرهنگ

### گروه سیاسی و امنیتی (۷ تا):
قضایی (حاکمیت قانون)، اطلاعات (سایبری)، اداره (کارآمدی)، انتخابات (شفافیت)، سیاست (ثبات)، آمار (دقت)، بحران (آمادگی)

### گروه زیرساخت و محیط (۸ تا):
محیط‌زیست (هوای پاک)، تاسیسات شهری (آب)، خدمات عمومی (پوشش سلامت)، راه‌ها (۱-ترافیک)، سکونتگاه (کیفیت مسکن)، میراث، فضا، صیادی

### گروه نظامی پیشرفته (۲ تا):
قدرت نظامی، جنگ تجاری (۱-دزدی دریایی×۲)

**نکته حرفه‌ای:** لنز **اقتصاد** + استان تهران → می‌بینی GDP سرانه خوزستان از سیستان بیشتره چون نفت - همونجا می‌تونی کارخانه بسازی

## <a id="لایه‌ها"></a>۴. ۹ لایه اطلاعاتی (چندانتخابی - پیل‌ها)

| لایه | چی نشون میده | رنگ |
|-----|--------------|-----|
| **جنگ** | خط مقدم بین کشورها | قرمز نقطه‌چین |
| **اتحاد** | خط اتحاد | آبی |
| **تجارت** | کریدور تجاری + توافق | سبز |
| **هوایی** | مسیر هوایی + هاب | آبی روشن |
| **دریایی** | مسیر دریایی + بندر | آبی تیره |
| **زمینی** | مرز زمینی + جاده مرزی | نارنجی |
| **شهرها** | پایتخت طلایی + شهر سفید | طلایی/سفید |
| **راه و ریل** | جاده از پایتخت به ۱۰ شهر + ریل نقطه‌چین | قهوه‌ای/سفید |
| **اطلاعاتی** | پوشش اطلاعاتی | بنفش |

**لایه ویژه `trade_disrupted` (خودکار):**
- وقتی حمله به مسیر فعال باشه، حتی اگر لایه تجارت خاموش باشه، **قرمز چشمک‌زن با انفجار وسط** نشون داده میشه
- مسیر: سایه سیاه + نقطه‌چین قرمز ضخیم + دایره نارنجی ضربان‌دار وسط + هسته زرد = انفجار

## <a id="انتخاب"></a>۵. انتخاب‌ها روی نقشه

### کشور:
- کلیک روی کشور → کارت `◉ کشور انتخابی: ترکیه`
  - رابطه با امتیاز `متحد/دوستانه/خنثی/متشنج/متخاصم` + `در جنگ` اگر جنگی
  - پایتخت، منطقه، جمعیت، GDP، مساحت، همسایگان، مسیر هوایی/دریایی، قدرت نظامی، فناوری
  - اگر در جنگ: **پنل جبهه** با پیشروی +٪، نسبت قوا، برتری هوایی، پیشروی روزانه km، ذخیره سوخت/مهمات، آسیب‌پذیری، کاروان‌ها
  - **۷ عملیات نقشه‌محور:** حمله هوایی ۱.۵ میلیارد، محاصره دریایی ۲.۵، خرابکاری زیرساخت، پهپاد انبوه ۲۰ فروند ۱.۲، سایبری ۰.۵، جنگ روانی، بشردوستانه +۲ نرم
  - ۱۰ عملیات دیپلماتیک: بهبود روابط، توافق تجاری، اتحاد، تحریم، جنگ، صلح

### استان/واحد اداری (زوم >۳.۶):
- کلیک روی استان → کارت `📍 استان تهران — ناحیه پایتخت`
  - جمعیت برآوردی + سهم + GDP + سرانه + مساحت + راه‌ها
  - **۳۳ سیستم کامل گروه‌بندی:**
    - 💵 اقتصاد ۸ تا (کشاورزی، صنعت، تجارت، گردشگری، بانک مرکزی، بورس، خرده‌فروشی، سوخت)
    - 👥 اجتماع ۷ تا (بهداشت، آموزش، رفاه، خانواده، ورزش، قومیت، فرهنگ)
    - 🏗️ زیرساخت ۸ تا (زیرساخت، تاسیسات شهری، خدمات عمومی، راه‌ها، سکونتگاه، محیط‌زیست، صیادی، میراث)
    - 🏛️ سیاست ۱۱ تا (قضایی، اطلاعات، اداره، انتخابات، سیاست، آمار، بحران، رضایت، امنیت، نظامی، فضا، ایثارگران)
  - **۶ عملیات نقشه‌محور:**
    - خودی: 🏰 استحکام‌سازی (+۲۰٪ دفاع)، ✈️ باند هوایی، 📦 انبار تدارکات (+۱۵٪)، 📡 رادار (+۲۰٪ شناسایی)، 🏭 کارخانه (+۱٪ تولید)، 🛡️ پناهگاه
    - دشمن: 💣 خرابکاری، ✈️ بمباران، 🛸 شناسایی پهپادی، 📢 تبلیغات، 🎯 عملیات ویژه، 🚧 محاصره منطقه‌ای

### شهر (زوم >۵.۲):
- کلیک روی شهر → پایتخت طلایی، شهر سفید، شعاع بر اساس جمعیت
- کارت پایتخت با جمعیت و فاصله

### مسیر تجاری:
- کلیک روی خط سبز تجارت → کارت `🗺️ کریدور انتخابی`
  - نوع (تجارت/هوایی/دریایی/زمینی)، مسیر، ظرفیت نسبی
  - اگر مختل: `⚠️ مختل` + وضعیت `🚫 مختل شده`
  - اگر گلوگاه: `⭐ هرمز - ۶ گلوگاه جهانی`
  - **۶ عملیات بر اساس نوع مسیر:**
    - تجاری: شبیخون ۱۵ روز، محاصره ۹۰ روز، خرابکاری ۳۰ روز، پهپاد انتحاری، سایبری ۱۰ روز، اسکورت محافظتی +۱۰٪ تجارت
    - دریایی: محاصره دریایی، مین ۱۸۰ روز، دزدی دریایی، اسکورت دریایی
    - زمینی: خرابکاری ریل/جاده، کمین، ایست بازرسی، گشت مرزی
    - هوایی: اخلال رادار، رهگیری، اسکورت هوایی
  - **پنل ۶ گلوگاه:** هرمز ۲۰٪ نفت جهان، سوئز ۱۲٪ تجارت، باب‌المندب، مالاکا، پاناما، جبل‌الطارق - هر کدام دکمه `🚫 محاصره`

## <a id="استان"></a>۶. مدیریت استان - ۳۳ سیستم روی نقشه

**قبل:** باید تب‌های جدا می‌رفتی

**الان:** روی استان کلیک → همه ۳۳ سیستمش رو می‌بینی و همونجا عملیات می‌زنی

**مثال - خوزستان:**
- جمعیت ۴.۷ میلیون (۵.۵٪ کشور)، GDP ۸٪ کشور (نفت)
- کشاورزی ۴۰٪ (نخلستان)، صنعت ۸۰٪ (پالایشگاه)، تجارت ۶۰٪
- بهداشت ۶۵٪، آموزش ۶۰٪، رفاه ۵۵٪ (فقر ۲۰٪)
- زیرساخت ۶۰٪، تاسیسات شهری آب ۷۰٪، محیط‌زیست ۴۵٪ (آلودگی نفتی)
- نظامی ۷۵٪ (مرزی)

**عملیات نقشه‌محور روی خوزستان (خودی):**
- 🏰 استحکام‌سازی → هزینه ۰.۶ میلیارد → دفاع استان +۲ سطح → بازدارندگی ملی +۰.۵
- ✈️ باند هوایی → ۱.۲ میلیارد → برد هوایی +۱۰٪
- 📦 انبار تدارکات → ۰.۵ میلیارد → آسیب‌پذیری تدارکات -۵٪ + ذخیره سوخت +۰.۵ روز
- 📡 رادار → ۰.۴ میلیارد → شناسایی +۲٪ + C4ISR +۰.۰۲
- 🏭 کارخانه → ۳.۰ میلیارد → تولید صنعتی +۱٪
- 🛡️ پناهگاه → ۰.۳ میلیارد → کاهش تلفات غیرنظامی

**اگر استان دشمن باشه (مثلا بصره عراق):**
- 💣 خرابکاری → انفجار پل/خط آهن
- ✈️ بمباران → خسارت زیرساخت -۰.۵٪
- 🛸 شناسایی پهپادی → اطلاعات +۱۰٪
- 📢 تبلیغات → روحیه دشمن -۵٪
- 🎯 عملیات ویژه → ترور فرمانده
- 🚧 محاصره منطقه‌ای → تدارکات دشمن -۱۵٪

## <a id="تجاری"></a>۷. جنگ تجاری - حمله به مسیرها روی نقشه

**لایه تجارت روشن + کلیک روی مسیر سبز:**

```
IRN → CHN : کریدور تجاری ۰.۹
عملیات:
🏴‍☠️ شبیخون - ۰.۵ میلیارد - ۱۵ روز اختلال - غنیمت
🚫 محاصره - ۲.۰ میلیارد - ۹۰ روز بستن کامل - نیاز به ناوگان
💣 خرابکاری - ۰.۸ میلیارد - انفجار پل - ۳۰ روز
🛸 پهپاد انتحاری - ۱.۰ میلیارد - دقیق
💻 سایبری - ۰.۳ میلیارد - اخلال ردیابی ۱۰ روز
🛡️ اسکورت - ۱.۵ میلیارد - محافظت +۱۰٪ تجارت
```

**بعد از حمله:**
- مسیر روی نقشه **قرمز چشمک‌زن** با سایه سیاه + نقطه‌چین ضخیم + **انفجار نارنجی ضربان‌دار وسط** (دایره ۵+sin*۲ + هسته زرد ۲.۵)
- پنل `🚢 جنگ مسیرهای تجاری - زنده` → حملات فعال ۲، گلوگاه مسدود ۱، دزدی ۳۵٪، اثر محاصره ۰.۴۵، خسارت ۲.۳ میلیارد
- اثر اقتصادی: صادرات -۲٪، واردات -۱٪، GDP -۰.۰۵٪، نفت -۰.۱/روز اگر هرمز باشه، تورم +، نفوذ -۲ اگر کشف بشه (۱۵٪ روز ۵)

**مثال واقعی:** محاصره هرمز → مسیر نفتکش‌ها قرمز → قیمت نفت +۱۰٪ → تورم شما +۰.۵٪ + تورم جهانی

## <a id="جبهه"></a>۸. جبهه و تدارکات - زنده روی نقشه

**وقتی در جنگی (مثلا با ترکیه):**

**جبهه:**
- خط مقدم از پایتخت شما تا پایتخت دشمن
- رنگ سبز اگر پیشروی >۰، قرمز اگر شکست، زرد اگر تعادل
- ضخامت بر اساس عرض جبهه km
- فلش جهت: ▲ به سمت دشمن اگر پیروزی، ▼ عقب‌نشینی اگر شکست
- متن: `جبهه TUR: +23.5` + زمین (دشت/کوهستان/شهری/بیابان) + هوا (آفتابی/بارانی/برفی) + تدارکات ۶۵٪ + هوایی ۷۰٪
- اگر کوهستان و دکترین چریکی داری → بونوس +۲۰٪ دفاع
- اگر بارانی → گل و لای → تدارکات ×۰.۸۵

**تدارکات:**
- خط نقطه‌چین از پایتخت شما تا جبهه (۷۰٪ مسیر)
- رنگ: سبز اگر امن (آسیب‌پذیری <۰.۴ و سوخت >۱۵)، زرد اگر پرخطر، قرمز اگر بحرانی (آسیب >۰.۶ یا سوخت <۵)
- کامیون متحرک سیاه با هاله رنگی روی مسیر - با `sin(ticks*0.0003)` حرکت می‌کنه
- اگر قرمز و کلیک کنی → `کمین به کاروان - ۵ کامیون سوخت منهدم`

**پنل جبهه در کشور خودت:**
- تعداد جبهه، ذخیره سوخت/مهمات روز، آسیب‌پذیری، کاروان‌ها
- متن راهنما: `خط مقدم با فلش پیشروی/عقب‌نشینی، خط تدارکات با کامیون متحرک`

## <a id="پیشرفته"></a>۹. طرح نبرد و ساخت‌وساز پیشرفته (HOI4)

| حالت | آیکون | نحوه کار |

**نحوه رسم فلش HOI4:**
1. حالت `⚔️ طرح نبرد` بزن → toast `مبدا ایران انتخاب شد - مقصد را انتخاب کن`
2. روی ترکیه کلیک → فرمان `battle_plan offensive IRN→TUR` → هزینه ۰.۳ میلیارد، آمادگی -۰.۳٪
3. روی نقشه فلش نارنجی از ایران تا ترکیه با `⚔️ تهاجم ۰٪` ظاهر میشه
4. هر روز پیشرفت `readiness*0.02 + (1-logistics)*0.01` → وقتی ۱۰۰٪ شد خودکار `world.wars[TUR].progress += ۳ تا ۷` + پیام `طرح نبرد اجرا شد`

**ساخت‌وساز:**
1. حالت `🛣️ ساخت جاده` → شهر تهران کلیک (مبدا) → اصفهان کلیک (مقصد) → جاده قهوه‌ای نقطه‌چین با `road ۰٪` وسط
2. هر روز پیشرفت `budget_share*0.05 + infra*0.02` → وقتی ۱۰۰٪ شد `infra.road_quality +۰.۰۱`
3. ساختمان ساخته‌شده: آیکون `🏰✈️📦📡🏭🛡️🎯⚓` روی نقشه با دایره زرد

**پنل طرح‌های فعال:**
```
📋 طرح‌های فعال: ۲ نبرد + ۱ ساخت‌وساز
```

## <a id="نکات"></a>۱۱. نکات حرفه‌ای

**ترکیب لنز + عملیات:**
- لنز **منابع** → ببین کدام استان آهن داره → لنز **صنعت** → همون استان کارخانه بساز
- لنز **جمعیت** + **نارضایتی** → استان ناراضی رو پیدا کن → لنز **رفاه** → بودجه رفاه بده
- لنز **قومیت** (۱-تنش) → استان با تنش قومی بالا → عملیات **تبلیغات/رفاه** از روی نقشه

**زنجیره تامین جنگی:**
1. قبل جنگ: حالت `📦 انبار` در استان مرزی بساز → ذخیره سوخت +۰.۵ روز، تدارکات -۵٪
2. حین جنگ: خط تدارکات سبز نگه دار - اگر قرمز شد یعنی کاروان‌ها کمین خوردن → `🛡️ اسکورت` بزن
3. اگر سوخت <۵ روز → حمله متوقف، پیشرفت -۱.۵ km/روز

**اقتصاد جنگی نقشه‌محور:**
- محاصره هرمز → نفت شما -۰.۱/روز → بحران انرژی → GDP -۱٪ → آمادگی نظامی -۰.۵٪ → شکست
- راه حل: `📦 انبار` + `🛣️ جاده` جایگزین + `📡 رادار` برای شناسایی کاروان دشمن

**دیپلماسی نقشه‌محور:**
- حمله به مسیر تجاری کشور بی‌طرف → ۱۵٪ شانس کشف روز ۵ → نفوذ -۲ + محکومیت
- حمله به مسیر دشمن در جنگ → مشروع، بازدارندگی +۰.۵

**میانبرهای نقشه:**
- `Ctrl+K` → فرمان سریع (command palette)
- دوبار کلیک کشور → ورود به کشور (زوم ۵)
- `Home` → کشور من، `۰` → جهان

**کارایی:**
- `reduce_motion` روشن → انیمیشن‌ها خاموش، باتری کمتر
- زوم <۲.۳ → افکت‌های زنده + ابر + موج اقیانوس
- زوم >۵.۲ → شهرها، >۶.۵ → شبکه راه و ریل
