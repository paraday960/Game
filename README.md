# Game

## 🧠 قوانین برای هوش مصنوعی (Agent Rules)

> ⚠️ **این قوانین الزامی است.** هر هوش مصنوعی (Agent) یا ابزاری که به این مخزن متصل می‌شود
> موظف است پیش از هر اقدام، این بخش را کامل بخواند و **تمام قوانین زیر را بدون استثنا رعایت کند.**

### ۱. کار تا حد امکان به‌صورت ریموت (Remote)
- تمام عملیات‌ها تا حد امکان **مستقیم و به‌صورت ریموت روی گیت‌هاب** انجام شود
  (از طریق API یا ابزارهای متصل به مخزن)، نه روی سیستم‌های محلی.
- در صورت نیاز به کار محلی، نتیجه همیشه باید در نهایت به‌صورت ریموت به مخزن برگردد.

### ۲. همه اصلاحات روی شاخه `main`
- **همه** تغییرات و اصلاحات باید **مستقیم روی شاخه اصلی (`main`)** اعمال شود.
- از ساخت برنچ‌های جدا و سپس ادغام (merge) خودداری شود؛ مگر در مواردی که به‌صراحت لازم باشد.
- پس از هر اصلاح، `main` باید همواره نسخهٔ سالم و قابل‌استفاده باشد.

### ۳. بارگذاری فوری و همیشه به‌روز بودن
- هر اصلاح باید **بلافاصله پس از انجام، روی گیت‌هاب بارگذاری (پوش/commit) شود.**
- هیچ تغییری نباید به‌صورت معلق و بدون بارگذاری بماند.
- مخزن باید **همیشه به‌روز** باشد؛ یعنی وضعیت روی گیت‌هاب با آخرین تغییرات اعمال‌شده یکسان باشد.

### ۴. شفافیت و مستندسازی
- تغییرات باید با پیام commit واضح و گویا ثبت شود.
- در صورت اضافه شدن قوانین یا ساختار جدید، همین بخش باید به‌روز شود.
