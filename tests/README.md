# تست‌های خودکار - شبیه‌ساز کشور

## اجرا (با Godot 4.2 هدلس)
```bash
godot --headless --path . --import                                  # آماده‌سازی (یک بار)
godot --headless --path . res://tests/test_scene.tscn              # تست واحد: موتور، ۶۵ سیستم، AIها
godot --headless --path . res://tests/test_long.tscn               # تست بلندمدت: ۳۶ ماه / بیش از ۱۰۰۰ روز داخلی
godot --headless --path . -s res://tests/test_ui.gd                 # تست دود UI: همه تب‌ها + فرمان‌ها

# تست واقعی ENet در دو پردازش (میزبان را پس‌زمینه اجرا کنید، سپس کلاینت):
godot --headless --path . -s res://tests/test_network_host.gd
godot --headless --path . -s res://tests/test_network_client.gd

# رقابتی دوکشوری روی پورت آزمایشی جداگانه:
godot --headless --path . -s res://tests/test_competitive_host.gd
godot --headless --path . -s res://tests/test_competitive_client.gd
```

## پوشش
- لود و اجرای همه‌ی سیستم‌ها در ترتیب دترمینستیک (هیچ سیستمی نباید لود ولی اجرا نشود)
- پیشروی ساعت: روز، ماه، سال و فصل
- قطعیت: دو اجرای هم‌سان = نتیجه‌ی کاملاً یکسان (قفل Lockstep - بخش ۳.۶)
- اعتبارسنجی `balance.json` و بارگذاری داده‌محور `initial_state.json`
- استریک، شتاب، XP، سطح و بازشدن دستاوردهای هفته/سال
- داده ۱۹۵ کشور، ۱۹۳ عضو سازمان ملل + ۲ ناظر، فیلد فارسی، منابع/مجوز و بازه اعداد
- انتخاب هر کشور/سناریو، دیپلماسی، تاریخچه جنگ و پیمان صلح
- کمپین رقابتی: دو State مستقل، فرمان مخصوص کشور و آشتی روابط/پیمان‌ها
- AI مستقل جهان: ماتریس رابطه، تجارت، اتحاد، جنگ و اثر اقتصادی
- توسعه نظامی: هزینه، زمان، پیش‌نیاز، تکمیل، دکترین و کاهش تلفات
- پروژه ملی: هزینه، پیشرفت، فساد، هوای شدید، تأخیر، اضافه‌هزینه و بهره‌برداری
- کابینه: انتصاب، سرمایه سیاسی، عملکرد، وزارتخانه خالی، فساد و انسجام
- عملیات اطلاعاتی: شروع، زمان، موفقیت، گزارش، افشا و پیامد دیپلماتیک
- قانون‌گذاری: تصویب، اجرای اداری، سرمایه سیاسی، تعارض، چالش قضایی و لغو
- خط زمانی: هش زنجیره، تشخیص دستکاری، Snapshot محدود و بازگشت ماهانه
- ابزارهای کلان: نرخ بهره، هدف تورم، استقلال بانک مرکزی و تعرفه
- شش سناریو، هدف نسبی/مطلق، مهلت روز-دقیق، پیروزی و پاداش یک‌باره
- نوبت ماهانه با ۲۹ تا ۳۱ روز داخلی، تقویم، فصل و نیم‌کره
- درخت ۲۰ فناوری، پیش‌نیاز، هزینه پژوهش و اثر چندسیستمی تکمیل
- تنظیمات محلی ماندگار: سرعت، متن، کنتراست، حرکت، صدا و راهنمای شروع
- اقلیم اجباری زمستان: برف‌روب، نمک، انسداد راه، اعتراض و تصمیم بحران
- ۱۲ سیاست عمومی، سرمایه سیاسی، اثر روزهای داخلی ماه، فعال/لغو و تعارض راهبردی
- تاریخچه ماهانه، سقف ۱۲۰ نمونه، خط پایه کشور و نمودار داشبورد
- پنج جایگاه ذخیره، فراداده، ذخیره خودکار و بازیابی خودکار فایل خراب از Backup معتبر
- مهاجرت خودکار ذخیره‌های قدیمی JSON و بازیابی EventLog
- اجرای بی‌خطای `decide` همه‌ی ۶۵ AI تخصصی (اصل ۷)
- تحلیل ۶۵ شاخص توسط شورای هوشمند و ساخت پیشنهاد اجرایی معتبر
- تبدیل رویداد به تصمیم چندگزینه‌ای، اعمال پیامد اتمی و ثبت تاریخچه
- انقضای تصمیم‌های بدون پاسخ و اعمال پیامد پیش‌فرض پس از ۳۰ روز
- رد فرمان ناشناخته و جلوگیری از تغییر وضعیت
- اتمی‌بودن EventLog: حذف کامل رویدادهای تراکنش Rollback
- پایداری بلندمدت: بدون NaN/Inf در ۳۶ نوبت و بیش از هزار روز داخلی
- UI: ساخت هر ۷ تب، نمودار روند، بازکردن جزئیات ۶۵ سامانه و اجرای فرمان‌های مالیات/دیپلماسی
- شبکه ENet واقعی: اتصال دو پردازش، فرمان کلاینت، Commit میزبان و Snapshot دارای checksum
- کد خروج غیرصفر در شکست؛ GitHub Actions پیش از ساخت APK تست‌های موتور، بلندمدت، UI و شبکه را اجرا می‌کند
